> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依 `design/v2/cli-flows.md`（63 項節點對照、41 張畫面稿）把互動選單樹重組為六區心智模型（Overview / Investigate / Alerting / Automation / Reports / System ＋ `G` 快捷鍵），統一畫面 chrome（`draw_panel` 小標頭框、每步驟 redraw、Current/Default 分開標示、破壞性動作確認框），click 子指令與參數介面零變動。

**Architecture:** 新增兩個共用模組——`src/cli/menu_chrome.py`（統一標頭框／確認框）與 `src/cli/health_line.py`（5 燈健康列，資料來源與 GUI dashboard overview 相同）——再新增 `src/cli/menus/areas.py` 承載六區選單函式；`src/main.py` 的 `main_menu()` 改為六區 dispatcher，舊容器 `rule_management_menu` / `report_generation_menu` 拆解吸收進 areas。三支 standalone 選單（pce_cache_cli / siem_cli / rule_scheduler_cli）只套 chrome＋補確認，內部表單流程不動。四型規則精靈＋report_schedule 精靈套 DD-1（每步驟 redraw）與 WZ-1（Current/Default）。最後以 63 項對照 parity 測試收斂。

**Tech Stack:** Python（既有 rich `draw_panel` renderer，不換）、pytest（互動測試沿用「monkeypatch `safe_input` / `builtins.input` 餵 iterator」慣例——本 repo 無 pexpect，不引入）、i18n `t()` 雙語 JSON。

```python
"""六區互動選單統一畫面 chrome（Phase 2C，cli-flows.md DD-1/WZ-3/§3.5）。"""
from __future__ import annotations

from src.i18n import t
from src.cli._render import Colors, draw_panel, safe_input


def clear_screen() -> None:
    print("\033[2J\033[H", end="", flush=True)


def menu_screen(path: str, lines: list, health: str | None = None,
                title: str = "Illumio PCE Ops") -> None:
    """清畫面＋統一標頭框：麵包屑＋（可選）健康列＋shortcuts＋內容。"""
    clear_screen()
    header: list = [f"{Colors.DARK_GRAY}{t('cli_path_label', path=path)}{Colors.ENDC}"]
    if health:
        header.append(health)
    header.append(f"{Colors.DARK_GRAY}{t('cli_shortcuts_compact')}{Colors.ENDC}")
    body = header + (["-"] + list(lines) if lines else [])
    draw_panel(title, body)


def confirm_box(title: str, impact_lines: list[str], ok_label: str) -> bool:
    """破壞性動作確認框（spec 2.3）：標題＋條列後果＋[N]/[Y]。預設 N。"""
    body = list(impact_lines) + [
        "-",
        f"{t('cli_confirm_cancel')}      [Y] {ok_label}",
    ]
    draw_panel(title, body)
    ans = safe_input(t("cli_confirm_prompt"), str, allow_cancel=False)
    return bool(ans) and ans.strip().lower() in ("y", "yes", "是")
```
