# Phase 2A — GUI 前端實作 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把閘門 2 放行的 `design/v2/mockup` 移植為 production 前端（`src/`），六區＋登入全面取代現有 8 分頁 GUI，接真 API、i18n 入庫、legacy e2e 遷移、102 項覆蓋 gate 改打真 app，最終部署測試機驗證。

**Architecture:** 移植不重設計——mockup 即規格與程式碼藍本。新前端先建於 `src/templates/v2/`＋`src/static/js/v2/`＋`src/static/css/v2/`，以 config 旗標路由 `/v2` 平行開發（CI 全程綠），最後一個切換任務把 `/` 指向新前端並刪舊檔。資料層差異集中封裝：mockup 的 `store.load(id)`（讀快照）換成 `api.load(id)`（打真端點），id→endpoint 對映的唯一事實來源是 `design/v2/tools/endpoints.yaml`。後端 97 端點零改動。

**Tech Stack:** Flask/Jinja（既有）、原生 ES modules（零 build）、CSS custom properties、Playwright（pytest 既有慣例：`ILLUMIO_OPS_E2E_BASE_URL` env-gated 真機測試＋in-process auth-bypass 本地測試兩軌）。

## Global Constraints（每任務隱含適用）

- **後端 API 零改動**：`src/gui/routes/`、`src/api/`、auth/CSRF/session 機制不動；僅新增 v2 模板/靜態檔路由與 config 旗標
- **規格權威=mockup**：`design/v2/mockup/**` 與 spec `docs/superpowers/specs/2026-08-03-ui-ux-redesign-v2-design.md`（§1.1 健康列=僅總覽）；`design/v2/` 目錄本身不修改（設計參考凍結）
- **id→endpoint 對映**：`design/v2/tools/endpoints.yaml`（32+10 條）為唯一事實來源；POST payload 欄位以該檔＋其註解的來源引用為準，不臆造
- **驗證面板（verifypane.mjs）不移植**；mockup 的 `__openAllForAudit`/`window.__open*` 稽核 hook **保留移植**（覆蓋 gate 與 e2e 依賴）
- 元件 teardown 契約：每區 unmount 必呼叫 `destroy()` 類方法（FilterBar/chart observer/window hooks）——每區任務驗收項
- a11y：drawer/modal focus trap＋`aria-modal="true"`＋關閉後焦點還原（T3 一次解決，各區沿用）
- i18n：新鍵進 `src/i18n/data/`（zh_TW＋en 成對），遵守七層白名單鏈（`_ui_translation_dict` 前綴白名單為第一層——v2 鍵統一 `gui_` 前綴改名入庫，不沿用 `v2_` 前綴以免撞白名單；`scripts/audit_i18n_usage.py` 必須 0）
- 禁止硬編色碼於 tokens.css 以外；密度只准動 token；NUL-free；no innerHTML（沿用 dom.mjs）
- 每任務結尾：`pytest -q` 全套綠（3750 基線）＋ `scripts/audit_i18n_usage.py` 0 ＋ commit（英文 conventional）
- Playwright 本地 e2e：沿用既有 in-process 模式（見 tests/test_gui_e2e_playwright.py 的 app fixture 與 auth bypass：`login_manager.session_protection=None` + `sess["_user_id"]`），所有新 e2e 檔比照 `pytest.importorskip("playwright.sync_api", exc_type=ImportError)` 防 CI 無瀏覽器
- 子代理派發硬規則（Phase 1 教訓）：worktree 釘選驗證、commit 前 `git rev-parse --show-toplevel` 證據、共用 worktree 禁 stash
