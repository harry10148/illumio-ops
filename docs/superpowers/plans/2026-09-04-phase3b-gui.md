# Phase 3B — GUI（Direction D token、五區 shell、首頁、調查中樞、各區搬遷）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已上線的 v2 GUI 原地演進成 v3：Direction D「品牌工作台」視覺、五區資訊架構、以「狀況＋待辦」為首頁、以「收件匣→流量→規則→行動」為調查中樞，接上 3A 的 `/api/alerts*` 與 `/api/policy/explain`。每個任務都是可獨立合併、CI 綠、部署測試機驗過的交付。

**Architecture:** **原地演進**，不開平行的 `v3/` 樹：`src/static/css/v2/{tokens,components,app}.css` 換 token 值與元件樣式，`src/static/js/v2/` 改 shell／路由／區域模組。理由：零 build 之下平行樹＝雙倍維護；四道 CSS 守門、`test_csp_compliance`、teardown 守門、離線 bundle 的 29 檔預期全綁在現有路徑上，原地改讓它們繼續有效。spec §5 寫的 `src/static/css/v3/tokens.css` 路徑因此**不採用**（本計畫更正）。舊 hash 路由全部保留為轉址，書籤不壞。

**Tech Stack:** 原生 ES modules（零 build）、Flask 模板、Playwright in-process e2e（CI 無條件跑 169 條）、`tools/gate_coverage_live.py`、四道 CSS token 守門、i18n audit。

**Spec:** `docs/superpowers/specs/2026-09-03-ui-redesign-v3-design.md` §1、§2、§3、§5（§4 已由 3A 交付）；路線圖 `docs/superpowers/plans/2026-09-03-ui-redesign-v3-roadmap.md`；比稿畫布 https://claude.ai/code/artifact/bedafd57-0972-43ad-8500-f80f361193ba（Direction D 首頁與調查中樞線框）；工作稿 `tmp/design-v3/Main.dc.html`（D 的 CSS 值來源）。

## Global Constraints

- 路線圖「全程約束」整段適用。
- **`data-cov` 錨點是承重選擇器**（e2e 170 處、coverage gate 全部靠它）：搬遷任何面板時錨點跟著走，不得改名；新面板才發新錨點，且**同一 commit** 寫進 `design/v3/coverage.yaml`（`extra == []` 是硬斷言）。
- i18n：所有新字串走 `gui_*` 鍵（伺服端白名單只放行 `gui_/sched_/status_/error_/pd_`），同 commit 進 `src/i18n_en.json`＋`src/i18n_zh_TW.json`；JS 內**禁止行尾 CJK 註解**（audit 類別 C）。
- CSP `font-src 'self'`／`script-src 'self'` 無 nonce：字型只能 `@font-face url("../../fonts/…")`，禁 Google Fonts；禁 inline script。
- 四道 CSS 守門原則不放寬：顏色只能在 `tokens.css`；間距／字級／圓角只能用 token；魔術 margin/padding ≤ 20；dark／light 的 `--tone-*-bg/fg` 必須不同值。Direction D 改的是**尺度值**，所以 `tests/test_css_space_type_tokens.py` 的 `EXPECTED_*` 在 Task 1 同 commit 改成 D 的值並附理由，不是刪斷言。
- `filter-bar.mjs` 維持零 import（`tests/design_v2/test_filterbar_semantics.py` 以 classic script 載入）。
- `core/store-map.mjs` 的 `GET_MAP` 必須逐行對應 `design/v2/tools/endpoints.yaml`（`tests/test_v2_coverage_live.py:35`）：新增 GET 端點＝同時加 endpoints 條目＋`design/v2/snapshots/<id>.json` 真快照（測試機擷取、遮罩）。
- 每區完成即部署測試機，Playwright 雙寬度（1280／800）截圖存 `tmp/phase3b-verification/<task>/`，亮色為主、暗色只驗不破版。
- 每任務結束：該任務測試檔＋`tests/test_v2_shell_flows_e2e.py`＋`tests/test_v2_coverage_live.py` 綠 → commit；orchestrator 在任務之間跑全套閘門。
- **待裁決項**（spec §1 ★）：頂欄五燈是否全頁常駐。本計畫以常數 `HEALTH_ROUTES` 實作，預設 `["#/home"]`（沿用 08-05 裁決）；使用者若同意常駐改成 `null`（全部路由）即可，不影響其他任務。
