最該做的 3 件事

  1. 把還在「只記錄、不擋」的主機切到開始擋。解決 2 項發現：勒索常用 port 沒被擋下、橫向移動 port 仍暢通。涉及 CoreServices、DemoApp、Traffic、K8sNode、onlineboutique。
