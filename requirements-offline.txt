# illumio_ops offline bundle dependencies — SOURCE SPEC ONLY.
# Derived from requirements.txt; HTML/XLSX/CSV/charts work on both online and offline builds.
#
# 這個檔案只寫版本「範圍」。實際下載與安裝一律走 requirements-offline.lock
# （pip-compile --generate-hashes 產生，逐檔 SHA256 釘選），bundle 內的
# install.sh / install.ps1 以 --require-hashes 安裝，雜湊不符即中止安裝。
#
# 改動本檔後必須重新產生鎖檔，否則 scripts/build_offline_bundle.sh 的新鮮度
# 閘門會擋下建置（鎖檔尾端的 sha256 標記與本檔內容不符）：
#
#   pip-compile --generate-hashes --strip-extras \
#       --output-file=requirements-offline.lock requirements-offline.txt
#   printf '# requirements-offline.txt sha256: %s\n' \
#       "$(sha256sum requirements-offline.txt | cut -d' ' -f1)" >> requirements-offline.lock
#
# Build command (Linux/WSL) — run by scripts/build_offline_bundle.sh:
#   pip download -r requirements-offline.lock --require-hashes \
#       --platform manylinux_2_17_x86_64 --python-version 3.12 \
#       --only-binary=:all: -d dist/wheels/linux/
#
#   pip download -r requirements-offline.lock --require-hashes \
#       --platform win_amd64 --python-version 3.12 \
#       --only-binary=:all: -d dist/wheels/windows/
#
# Note: transitive binary dependencies (numpy, pillow, contourpy, etc.) are
# resolved and pinned into the lock by pip-compile — do not list them here
# unless an environment marker hides them from the Linux build host (see the
# Windows-only section at the bottom).

# ── manylinux_2_17 相容性上界（transitive deps，非直接使用）────────────────────
# Linux wheels 是以 --platform manylinux_2_17_x86_64（glibc 2.17）下載的。下列
# 套件的新版只發 manylinux_2_28 wheel，鎖檔若釘到那些版本，pip download 會直接
# 失敗——釘了雜湊以後就不能再像以前那樣自動回退到舊版。
#
# Linux 這邊不是降版：現行未釘版的建置本來就是靠 pip 回退拿到同樣這幾個版本，
# 這裡只是把「實際會裝到什麼」寫死、寫明。Windows 這邊則是被 Linux 拖著一起釘
# （同一份鎖檔要同時供兩個平台下載，版本只能取交集）。
#
# 代價：這幾個套件實質凍結在最後一版有 manylinux_2_17 wheel 的版本，上游不會再
# 回頭發 2_17。pillow 12.2.0 目前就帶著 13 個已知漏洞（修正版 12.3.0 起只發
# manylinux_2_28）；本專案不解析外部影像（pillow 只是 matplotlib 產圖的相依），
# 觸及不到，CI 的 pip-audit 以具名 ID 放行、有新漏洞照樣擋。
# 真正的解法是把 Linux 目標平台提升到 manylinux_2_28（docs/guide/installation.md
# 列的 RHEL/Rocky 8+、Ubuntu 22.04+、Debian 12+ 其實都 >= 2.28，只有文件裡那句
# glibc >= 2.17 和 preflight.sh 的門檻更寬），做完這整段上界就能刪掉——那是產品
# 決定，不在這裡順手改。
argon2-cffi-bindings<=21.2.0
contourpy<=1.3.2
greenlet<=3.2.4
pandas<=2.3.2
pillow<=12.2.0
